Formeldreieck im Kopf

Druck berechnen
p = F / A
Formel umstellen
F = p · A    |    A = F / p
Einheiten: Für Ergebnisse in Pascal gilt: 1 Pa = 1 N/m². Deshalb muss die Fläche in m² eingesetzt werden.

Aufgaben

1. Druck berechnen

Auf eine Fläche wirkt eine Kraft von 40 N.

F = 40 N    A = 0,020 m²

Berechne den Druck.

Pa
Setze in p = F/A ein: 40 N ÷ 0,020 m².
Lösung: p = 2 000 Pa.

2. Kraft berechnen

Ein Druck von 3 000 Pa wirkt auf eine Fläche von 0,015 m².

p = 3 000 Pa    A = 0,015 m²

Berechne die Kraft.

N
Stelle die Formel um: F = p · A.
Lösung: F = 45 N.

3. Fläche berechnen

Eine Kraft von 60 N soll einen Druck von 5 000 Pa erzeugen.

F = 60 N    p = 5 000 Pa

Wie groß muss die Fläche sein?

m²
Stelle um: A = F/p.
Lösung: A = 0,012 m².

4. Erst die Fläche umrechnen

Eine Person drückt mit 600 N auf eine Fläche von 100 cm².

F = 600 N    A = 100 cm²

Berechne den Druck in Pascal.

Pa
100 cm² = 0,010 m². Danach p = F/A.
Lösung: p = 60 000 Pa.

5. Vergleich: kleinere Fläche

Die gleiche Kraft von 600 N wirkt jetzt nur auf 50 cm².

F = 600 N    A = 50 cm²

Berechne den Druck.

Pa
50 cm² = 0,0050 m². Vergleiche dein Ergebnis mit Aufgabe 4.
Lösung: p = 120 000 Pa. Halbiert sich die Fläche, verdoppelt sich hier der Druck.
